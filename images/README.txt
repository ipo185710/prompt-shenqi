效果圖資料夾

把提示詞的效果圖放在這個 images 資料夾內。

建議命名：
white-background-product.jpg
product-retouch-01.jpg
4k-upscale.jpg
remove-object.jpg

上傳到 GitHub 後，圖片網址格式：
https://prompt-shenqi.vercel.app/images/檔名.jpg

例如：
https://prompt-shenqi.vercel.app/images/product-retouch-01.jpg

在提示詞神器編輯 Prompt 時，把網址貼到「效果圖網址（可選）」即可。
